## 0. 準備（ここが一番間違えやすい）

ターミナルで：

```bash
cd ~/FireFlow/live-board-nextjs
npm run dev
```

**表示されたURL（`http://localhost:3000` とは限りません）をそのまま開いてください。**

> なぜ注意が必要か：2026-08-15の無人実行時、ポート3000には**古いdev server**が
> 動いたままでした。古いdev serverは新捺印表の読み取り先
> `/api/v1/standardized-stamp-sheet/scan` を持っておらず、**404**を返します。
> その状態で画像を読ませると「読み取りに失敗しました」となり、
> Phase 2が壊れているように見えてしまいます。
> 心配な場合は、開いているターミナルをすべて閉じてから上の手順をやり直してください。
> 新しく起動したdev serverでは、このURLが正しく応答することを確認済みです。

> **もう1つの落とし穴：画面が「Application error」やエラーページになる場合（2026-08-15追記）**
> dev serverを起動したまま `npm run build` を実行すると、両者が同じ `.next/` を使うため
> 起動中のdev serverの内部ファイルが入れ替わり、`Cannot find module './xxx.js'` で
> **エラーページ（500）**が出ることがあります。**これはコードの不具合ではありません。**
> dev serverを一度止めて `npm run dev` で起動し直せば直ります。
> （実LB確認中は `npm run build` を実行しないでください。build は無人実行側で済ませてあります）

開いたら**ログイン**してください（未ログインだと読み取りは401で止まります）。

## 3. 部屋カードを見る（4部屋だけ）

☑ **確認③**

| 部屋 | 期待する表示 |
|---|---|
| **1101** | **A** と **09:30** |
| **801** | **A** と **09:30** と 備考 **朝一** |
| **802** | **要確認** バッジ。**AもPも出ない** |
| **1102** | 部屋カードはある。**予定情報は何も出ない** |

> **2026-08-15の修正後に見え方が変わる点（801の備考）**
> AIが備考を「朝一」以外の似た文字（例：斡一）で返した場合、これまでは備考が
> **画面から完全に消えて**いました。修正後は、**読み取った文字がそのまま**部屋カードに出て、
> その部屋に「要確認」バッジが付きます（原本を確認してください、という意味です）。
> 「朝一」と出れば確定、似た別の文字＋要確認バッジなら**この修正が効いている状態**です。
> 何も出ない場合だけ、これまでどおりの不具合です。
>
> **801が「Aだけ」で09:30も朝一も出ない場合（前回の実LBで起きた症状）**
> そのときは必ず**確認②-2のパネル**を見てください。そこに `09:30 備考「朝一」` が
> 出ていれば、原因は**AIが801の部屋番号のマスを読めなかったこと**だと確定します
> （パイプラインの不具合ではありません）。**パネルに出ている文字をそのまま**教えてください。
> 読み込みのやり直しは不要です。パネルにも何も出ない場合だけ、これまでどおりの不具合です。
>
> **1101で確認したいこと**：09:30が出れば修正成功です。もし今回も要確認のままなら、
> **1101の「要確認」バッジを長押し（PCならマウスを乗せる）**して出る説明文を教えてください。
> `TIME_START:...(9?:30)` のように、AIが返したマスの中身が出るようになっています。
> それだけで原因が特定できます（読み込みのやり直しは不要です）。
